# Human Activity Recognition using Smartphone Sensor Data

This project focuses on classifying **human physical activities** such as walking, sitting, standing, and more, using **sensor data collected from smartphones**. The goal is to develop a machine learning model capable of accurately predicting activity types based on accelerometer and gyroscope readings, with **extensive data visualization** to explore and understand patterns.


## 📌 Project Overview

Human activity recognition (HAR) is important for **healthcare, fitness tracking, and context-aware computing**. This project leverages smartphone sensor data and applies multiple machine learning algorithms to classify activities in real time.

The project includes **rich visualizations** for:

* Accelerometer and gyroscope signal patterns per activity
* Feature distributions and correlations
* Model performance comparisons


## 🧠 Machine Learning Algorithms Used

* **Logistic Regression**
* **Random Forest**
* **Support Vector Machine (SVM)**
* **Decision Tree**


## 📂 Dataset

* The dataset includes **accelerometer and gyroscope readings** from participants performing activities such as **walking, sitting, standing, climbing stairs, and lying down**.
* Labels are used to train and evaluate models for supervised classification.


## 📊 Data Visualization

* **Signal plots** of accelerometer/gyroscope readings over time per activity.
* **Correlation heatmaps** to understand relationships between sensor features.
* **Distribution plots** for each feature to identify patterns.
* **Confusion matrices** to visualize model performance across activities.
